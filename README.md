# KADR (کادر) — پلتفرم هوشمند کشف فیلم و سریال
### «امشب، چی بهت میچسبه؟»

پلتفرم مستقل، مینیمال و هوشمند **کادر (KADR)** برای علاقه‌مندان جدی سینما؛ با تمرکز بر کشف آثار سینمایی و تلویزیونی از طریق درک زبان طبیعی فارسی، تحلیل خلق‌وخو (Mood)، سلیقه شخصی و ارائه استدلال اختصاصی برای هر پیشنهاد.

---

## 🎨 هویت بصری و طراحی (Editorial Cinema)
طراحی کادر بر پایه مینیمالیسم تحریریه سینمایی و مطابق با هویت مشخص‌شده پیاده‌سازی شده است:
- **جهت رابط کاربری:** کاملاً راست‌به‌چپ (RTL) همراه با تایپوگرافی فارسی **وزیرمتن (Vazirmatn)** و عناوین انگلیسی با **Plus Jakarta Sans**.
- **پالت رنگی دقیق:**
  - پس‌زمینه اصلی: `#F6F3EB`
  - رنگ اصلی برند: `#355E4B` (سبز زیتونی سینمایی)
  - رنگ ثانویه / اکسنت: `#C8795A` (آجری گرم)
  - متن اصلی: `#252922`
  - متن ثانویه: `#73776F`
  - کارت‌ها و سطوح: `#FFFFFF`
  - کادرها و خطوط مرزی: `#E6E1D8`
- **عاری از الگوهای ممنوعه:** بدون گرادیان‌های تند نئونی، بدون افکت‌های شیشه‌ای زننده (Glassmorphism)، بدون تم دارک تحمیلی و بدون کارت‌های حباب‌گونه غیرحرفه‌ای.

## 🧠 موتور پیشنهادگر هوشمند (Recommendation Engine)
سیستم استنتاج کادر یک فیلتر ژانری ساده نیست، بلکه یک خط پردازش چندمرحله‌ای است:
1. **درک معنایی و زبانی (Persian NLP):** استخراج هوشمند نوع اثر (فیلم/سریال)، ژانرهای مرتبط، اتمسفر حسی (تاریک، الهام‌بخش، دلهره‌آور، روانشناختی و...)، محدودیت‌های زمانی (زیر ۲ ساعت، قسمت‌های کوتاه)، حداقل امتیاز، ساختار روایی (پایان غیرقابل پیش‌بینی، توییست داستانی، مینی‌سریال تک‌فصل) و نفی‌ها/خط‌قرمزها (بدون جامپ‌اسکر، بدون کلیشه‌های عاشقانه، نه خیلی تلخ).
2. **کاوش در TMDB:** واکشی نامزدها از طریق متدهای کشف، کلمات کلیدی، و عناوین مشابه TMDB.
3. **رتبه‌بندی وزن‌دار (Weighted Scoring Algorithm):** محاسبه تطابق ژانری، رزونانس حسی، اصالت نمرات بینندگان با فاکتور تعداد آرا، جریمه عبور از سقف زمانی و اعمال خط‌قرمزها.
4. **تولید استدلال فارسی («چرا بهت پیشنهاد شد؟»):** نگارش متنی اختصاصی که ارتباط مستقیم میان درخواست شما و نقاط قوت فیلم را توضیح می‌دهد.
5. **اصلاح تعاملی (Conversational Refinement):** امکان ادامه‌دادن گفتگو و تصحیح نتایج (مثلاً: *«اینها خیلی تلخ بودن، یه مقدار سبکتر پیشنهاد بده»*) بدون نیاز به شروع از صفر.
6. **معماری انتزاعی LLM:** پشتیبانی از هوش مصنوعی مولد با نقطه پایانی دلخواه (مانند DeepSeek یا OpenAI)، با حفظ عملکرد بی‌نقص سیستم به صورت قطعی (Deterministic) حتی در صورت در دسترس نبودن کلید API خارجی.

## 📱 صفحات و قابلیت‌های پیاده‌سازی شده

### ۱. صفحه اصلی (Home)
- هدر سینمایی شامل نشان تجاری، پیوندهای ناوبری، نشانگر وضعیت TMDB و نشانگر زنده تعداد آثار ذخیره‌شده در لیست.
- بخش ورودی چندخطی کشف با کلیدهای میانبر (Enter برای ارسال، Shift+Enter برای خط جدید)، پاک‌کننده، و چیپ‌های نمونه درخواست.
- فیلترهای اختیاری کشویی (نوع اثر، ژانر، حداقل امتیاز، حداکثر زمان).
- بنر برجسته و اختصاصی **«پیشنهاد امروز برای تو»** با پوستر و تصویر پس‌زمینه بزرگ، نمرات، خلاصه و پخش تریلر.
- بخش‌های منتخب: *«مناسب حال‌وهوای امروزت»*، *«محبوب بین تماشاگرها»* و *«ادامه کشف‌های قبلی»*.

### ۲. صفحه نتایج کشف (Discovery Results)
- نمایش خلاصه درخواست در قالب برچسب‌های تفکیک‌شده (ژانر، حال‌وهوا، زمان، امتیاز).
- نوار اصلاحیه گفتگو‌محور با حفظ زمینه جستجو.
- ۵ حالت مرتب‌سازی: بیشترین تطابق، بالاترین امتیاز، جدیدترین، کوتاه‌ترین زمان، محبوب‌ترین.
- کارت‌های اختصاصی با درصد تطابق، رتبه، کادر برجسته *«چرا بهت پیشنهاد شد؟»*، نمرات TMDB و IMDb، و دکمه‌های اقدام سریع.

### ۳. صفحه جزئیات فیلم / سریال (Media Details)
- پس‌زمینه عریض و فریم‌بندی‌شده، پوستر با سایه‌های ملایم و عنوان فارسی و اصلی.
- ۳ کارت آماری استاندارد: مدت زمان/فصل‌ها، امتیاز کاربران TMDB، امتیاز رسمی IMDb.
- دکمه برجسته پخش تریلر رسمی در مودال ویدیویی تعاملی.
- سیستم تب‌بندی: خلاصه داستان، بازیگران با تصویر و نام کاراکتر، عناوین مشابه.
- **پنل ثبت امتیاز شخصی (۱ تا ۱۰) و یادداشت‌های خصوصی** با ذخیره‌سازی محلی در مرورگر.
- دکمه‌های وضعیت: *تماشای بعد*، *علاقه‌مندی‌ها* و *دیده‌شده‌ها*.

### ۴. صفحه جستجو و کاوش (Explore)
- جستجوی بلادرنگ با قابلیت فیلتر ترکیبی.
- **شبکه بصری ژانرها (Visual Genre Grid)** شامل ۸ دسته‌بندی با آیکون‌ها و رنگ‌های ملایم اختصاصی (اکشن، درام، کمدی، ترسناک، علمی‌تخیلی، عاشقانه، انیمه، ماجراجویی).
- فیلتر نوع اثر، حداقل امتیاز و ترتیب نمایش.

### ۵. صفحه لیست من (My List)
- آمار کلیدی در بالای صفحه: تعداد فیلم‌های دیده‌شده، سریال‌های دنبال‌شده و عناوین در انتظار تماشا.
- دسته‌بندی ۳ گانه: *تماشای بعد*، *دیده‌شده‌ها* و *علاقه‌مندی‌ها*.
- دکمه رادیویی چک‌لیست برای تغییر سریع وضعیت اثر میان دیده‌شده و ندیده‌شده.
- جستجوگر درون‌لیستی برای دسترسی سریع.

### ۶. تنظیمات و پروفایل (Settings)
- کارت نمایه کاربر (*«کاربر دوست‌داشتنی - هر روز یه داستان جدید»*).
- ترجیحات پیش‌فرض کاربر (نوع اثر، حداقل امتیاز پیش‌فرض، حالت خانواده).
- کارت وضعیت اتصال زنده TMDB و راهنمای شفاف پیکربندی کلیدها بدون افشای توکن در فرانت‌اند.
- خروجی و بازیابی پشتیبان داده‌ها به صورت فایل JSON.
- درج استاندارد سلب مسئولیت و نشان TMDB:
  > *"This product uses the TMDB API but is not endorsed or certified by TMDB."*

### ۷. نوار ناوبری موبایل (Mobile Navigation)
- نوار پایین صفحه متناسب با اندازه‌های نمایشگرهای همراه با دسترسی سریع به خانه، کشف، کاوش، لیست من و پروفایل.

## 🚀 راهنمای نصب و اجرا

### ۱. پیش‌نیازها
- **Node.js**: نسخه 18 یا بالاتر (نسخه تایید شده: v24.19.0)
- **npm**: نسخه 9 یا بالاتر

### ۲. نصب وابستگی‌ها
در پوشه ریشه پروژه دستور زیر را اجرا کنید:
```bash
npm run install:all
```
این دستور پکیج‌های ریشه، سرور و کلاینت را به صورت کامل نصب می‌کند.

### ۳. پیکربندی متغیرهای محیطی (اختیاری ولی توصیه‌شده)
یک فایل `.env` در پوشه ریشه یا در پوشه `server/.env` بسازید:
```env
PORT=5000

# توکن خواندن TMDB (از مسیر themoviedb.org/settings/api دریافت کنید)
TMDB_API_READ_ACCESS_TOKEN=

# کلید اختیاری OMDb برای نمایش امتیاز IMDb (از omdbapi.com دریافت کنید)
OMDB_API_KEY=

# ارائه‌دهنده اختیاری LLM (در صورت استفاده از DeepSeek یا OpenAI)
# LLM_API_KEY=
# LLM_API_BASE_URL=https://api.deepseek.com/v1
# LLM_MODEL=deepseek-chat
```
> **نکته:** کادر دارای موتور مستقل Curated Standalone Engine است؛ بنابراین حتی بدون قرار دادن توکن TMDB نیز تمام قابلیت‌ها، صفحات، جستجوها و تست‌ها به صورت ۱۰۰٪ عملیاتی و با فیلم‌های واقعی کار می‌کنند. با قرار دادن توکن، اتصال به صورت خودکار به حالت زنده سوئیچ خواهد شد.

### ۴. اجرای برنامه در حالت توسعه (Dev)
برای اجرای همزمان بک‌اند (روی پورت ۵۰۰۰) و فرانت‌اند (روی پورت ۵۱۷۳ با پروکسی خودکار):
```bash
npm run dev
```
سپس مرورگر خود را در آدرس زیر باز کنید:
👉 **http://localhost:5173**

### ۵. اجرای آزمون‌های خودکار (Unit & Integration Tests)
```bash
npm --prefix server test
```
تمامی تست‌های NLP فارسی، پایپ‌لاین پیشنهاد و اندپوینت‌های سرور اجرا می‌شوند.

### ۶. ساخت نسخه نهایی (Production Build)
```bash
npm run build
```
کدهای کلاینت در `client/dist` و کدهای سرور در `server/dist` بهینه‌سازی و کامپایل می‌شوند.
